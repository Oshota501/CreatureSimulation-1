# 魚の強化学習（PyTorch + GPU / pygame）

尻尾とヒレで泳ぐ魚が、正面のセンサーで餌を見つけて食べに行くことを **PPO** で学習します。
シミュレーションは PyTorch のテンソル演算で書かれていて、**GPU 上で数千の水槽を同時に**動かして学習します
（Apple Silicon なら MPS、NVIDIA なら CUDA を自動で使います）。

## セットアップ

```bash
python3.13 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

## 使い方

```bash
.venv/bin/python train.py            # 学習（M4 で約2分、checkpoints/fish_ppo.pt に保存）
.venv/bin/python play.py             # 学習した魚を見る
.venv/bin/python play.py --watch     # 学習中に別ターミナルで実行すると、賢くなっていく様子をライブで見られる
.venv/bin/python play.py --manual    # 自分で魚を操作してみる
```

### play.py のキー操作

| キー | 動作 |
|---|---|
| SPACE | 一時停止 |
| TAB | AI / 手動 の切替 |
| G | AI の行動を 確率的 / 貪欲（最も確率の高い行動）で切替 |
| A / D | 尻尾を左 / 右へ振る（交互に押すと進む） |
| W | 尻尾を自動で振り続ける（手動モード用） |
| Q / E | 左 / 右ヒレを開く（開いた側に曲がる） |
| + / - | 再生速度 |
| R | リセット |
| V | センサー表示の ON/OFF |

## しくみ

### 魚の体（`fish_env.py`）

- **尻尾**（行動: 左へ振る / 力を抜く / 右へ振る）
  尻尾には慣性があり、**振りの速さの2乗**に比例して前へ進む力が出ます。
  片側に振りっぱなし・小刻みに震わせるだけではほとんど進まず、**左右に大きく交互に振る**リズムを覚える必要があります。
  振った反動で頭も少し左右に振られます。
- **胸ビレ**（行動: 左ヒレ 開/閉、右ヒレ 開/閉）
  開いた側に水の抵抗が生まれ、その側へ曲がります。速く泳いでいるほどよく曲がり、両方開くとブレーキになります。
- **正面センサー**
  頭の先から前方 120° の視野を 11 個の扇形に分け、それぞれの扇形で一番近い餌の「近さ」(0〜1) を出力します。
- **壁センサー**
  頭から 5 本のレイを飛ばして壁までの近さを測ります。
- **報酬**
  口が餌に触れたら +1。食べた餌は別の場所に再出現します（それ以外の報酬はなし）。

### 観測（ネットワークへの入力、21次元）

`[正面センサー 11] + [壁センサー 5] + [尻尾の角度, 尻尾の速度, 前進速度, 横滑り速度, 旋回速度]`

### 学習（`train.py`, `model.py`）

- PPO（Actor-Critic、隠れ層 256×2）
- 2048 水槽 × 64 ステップ = 13万サンプルを GPU 上で集めて 1 回更新
- 行動は「尻尾(3択)・左ヒレ(2択)・右ヒレ(2択)」の3つのカテゴリ分布を同時に出力

主なオプション:

```bash
.venv/bin/python train.py --total-steps 60e6     # もっと長く学習
.venv/bin/python train.py --num-envs 4096        # 水槽を増やす（GPU なら速くなることが多い）
.venv/bin/python train.py --approach-coef 0.02   # 「餌に近づいたら少し報酬」の補助報酬を追加
.venv/bin/python train.py --resume               # 保存済みモデルから続きを学習
.venv/bin/python train.py --device cpu           # CPU で学習
```

物理パラメータ（水の抵抗、ヒレの効き、視野角、餌の数など）は `fish_env.py` の `FishConfig` で変更できます。

# 進化シミュレーション（evo_world.py / evo_play.py）

ゲーム「Species」のように、学習ではなく**自然選択**で生き物が変わっていくシミュレーションです。
尾びれの物理とセンサーは上の魚と同じで、1つの水槽に数百〜2000匹が同時に暮らします。
体の形やヒレの付き方も遺伝子で決まるので、世代を重ねると見た目の違う種に分かれていきます。

```bash
.venv/bin/python evo_play.py                            # 新しい世界で開始
.venv/bin/python evo_play.py --load saves/world.pt      # 保存した世界の続きから（S キーで保存）
.venv/bin/python evo_play.py --headless --steps 50000   # 画面なしで一気に進めて saves/world.pt に保存
```

| キー / マウス | 動作 |
|---|---|
| SPACE | 一時停止 |
| + / - | 再生速度（×1 〜 ×32、MAX） |
| マウスホイール | ズーム |
| 右ドラッグ / 矢印キー | カメラ移動 |
| 左クリック | 個体を選択（ヒレの付き方・遺伝子・センサーを表示。パネルに拡大図） |
| F | 選択した個体を追いかける |
| C | カメラを元に戻す |
| R | 植物の雨（よく生える場所の分布に従って 300 個撒く） |
| H | 植物がよく生える場所の表示 ON/OFF |
| S | 世界を保存 |
| 1〜5 | ツールの切り替え（下の表） |
| [ / ] | ブラシを小さく / 大きく |
| < / > | 植物の生える速さを下げる / 上げる |

## 植物の出現を操作する

画面下のツールバー（またはキー 1〜5）でツールを選び、水槽の中をクリック・ドラッグします。

| ツール | 左クリック / ドラッグ | 右クリック |
|---|---|---|
| 1 select | 個体を選ぶ | カメラ移動 |
| 2 feed | ブラシの円の中に植物を撒く | カメラ移動 |
| 3 erase | ブラシの円の中の植物を消す | カメラ移動 |
| 4 spot | 「よく生える場所」を置く（広さ＝ブラシの大きさ）。既存の場所の中心をドラッグすると移動 | その場所を消す |
| 5 spawn | 生き物を置く（押し続けると少しずつ、Shift+クリックでブラシの範囲に 10 匹）。個体を選択中ならその子（遺伝子が少し違う同じ家族）、選択していなければ完全にランダムな個体 | カメラ移動 |

| ツールバーの項目 | 内容 |
|---|---|
| grow | 自然に生える速さ（OFF・×0.25〜×8） |
| max | 自然に生える上限の数（手で撒く分はこれを超えてもよい。枠の上限は 2000） |
| brush | ブラシの大きさ |
| rain / clear | まとめて 300 個撒く / すべて消す |

生える速さ・上限・よく生える場所は、S キーで保存すると世界と一緒に保存されます。

## ルール

- **エネルギー**: 生きているだけ・泳ぐだけで減り、餌を食べると増える。0 になると死ぬ（寿命もある）
- **出産**: エネルギーが一定以上たまったら子を産み、エネルギーを分け与える
- **遺伝**: 子は親の遺伝子を少しだけ突然変異させて受け継ぐ。最初の個体だけ完全にランダム
- **トレードオフ**: 大きい体・大きな尾びれ・広く遠くまで見える目・たくさんのヒレは有利だが、そのぶんエネルギーを多く使う

## 体のつくり（すべて遺伝子で決まる）

| 部位 | 遺伝子 | 働き |
|---|---|---|
| 体 | 大きさ・長さ・太さ・一番太い位置 | 細長いと水の抵抗が小さいが曲がりにくい。太いとエネルギーを多くためられる |
| 尾びれ | 大きさ・切れ込み | 左右に振ると前進。大きいほど速いが疲れる |
| ヒレ（最大3対） | 大きさ・付く位置・向き | 向いている方向へ水を押し、体は逆向きに押される。脳が1枚ずつ動かす |
| 目 | 視野角・見える距離 | 視野が広いほど目が横に付き、遠くまで見えるほど目が大きい |
| 模様 | 縞の本数・模様の色・体色 | 見た目だけ。少しずつずれていくので、家族ごとに見た目が分かれる |
| 脳 | 小さなリカレントネットワークの重み | センサーを見て尾びれとヒレを動かす |

## 捕食（食べる・食べられる）

| 仕組み | 内容 |
|---|---|
| 噛みつき | **頭（口）が相手の体に触れている**ときに、脳が「噛む」を選ぶと噛みつく。正面からでも背後からでも、口が当たれば噛める |
| 攻撃力 | 顎（jaw）が強く、頭と体が大きいほど深く噛める。顎は持っているだけでエネルギーを使う |
| 防御 | 鎧（armor、体の横のトゲ）が強いほど受けるダメージが減る。ただし重くなり燃費も悪い |
| 体力 | 体重に比例。噛まれると体力とエネルギーが減り、体力が 0 になると死ぬ。少しずつ回復する |
| 死体 | 死んだ個体（餓死・寿命も含む）は **体重に比例したエネルギーの肉** になる。少しずつ腐って小さくなる |
| 食性 | diet が 0 に近いほど植物を、1 に近いほど肉を効率よく消化できる。肉食ほど瞳が赤い |
| センサー | 植物・肉・他の個体に加え、見えた相手が自分より大きいか、肉食かも分かる |

最初は顎も鎧も弱い個体から始まり、肉食の種・鎧で身を守る種がだんだん進化してくる。
パネルのグラフには植物（緑）・草食（黄）・肉食（赤）の数が表示される。

ヒレの例:
- 顔に前向きのヒレ → 使うと**バック**する
- 後ろ向きのヒレ → 使うと前に進む（尾びれより遅い）
- 前のほうの横向きのヒレ → その場で**旋回**（左のヒレで右に曲がる）
- 大きさが 0 以下のヒレは生えない。ヒレは持っているだけでエネルギーを使うので、役に立たないヒレは世代を重ねると**退化**する

## 最初は誰も餌を食べられない問題への対策

1. **生まれつきの遊泳リズム**（本物の魚の CPG と同じ考え方）: ランダムな脳でも尻尾をリズムよく振れる
2. **エデンの園**: 最初は餌が満杯。個体が増えると餌が減り、自然に競争が始まる

個体数が減っても自動では補充しません。全滅したときや新しい生き物を足したいときは、ツール「5 spawn」でマウスから置きます（パネルの `spawned` に置いた数が出る）。

## GPU での計算

- 全個体 × 全餌、全個体 × 全個体 のセンサー計算を GPU でまとめて行い、`torch.compile` で1つのカーネルに融合（約16倍速）
- 個体ごとに違う脳の重みを 3 次元テンソルにまとめ、全員分を一度に計算
- 個体の枠を固定数（2048）用意し、死んだ枠に子が生まれる。出産の組み合わせも GPU 上で完結

世界の設定（広さ・餌の量・エネルギーの収支など）は `evo_world.py` の `EvoConfig` で変更できます。
